# ParkingUSA Mobile

Mobile application workspace placeholder.

Use this folder for the future mobile app so it stays separate from the website
in `apps/frontend` and the shared backend in `apps/backend`.

Suggested structure:

- `src/` - mobile application source code.
- `assets/` - mobile-only images, icons, fonts, and other bundled assets.
- `tests/` - mobile-specific tests once a mobile framework is selected.
